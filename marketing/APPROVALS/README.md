# Approval Queue

Every piece of content that could go public lands here first, as its own file, before posting. Nothing in this folder is live until you approve it and it's moved to "posted" status in the content calendar.

## File naming
`YYYY-MM-DD_platform_short-description.md`

## Required fields per item
- Platform + target community (subreddit / TikTok)
- Full content (post text / comment text / video script)
- Which content pillar it serves
- Whether it includes a link, and the exact UTM-tagged URL if so
- Self-check against voice.md "never" list
- Self-check against that subreddit's verified rules (link to the entry in subreddits.md)

## Your review options
Approve as-is / edit then approve / reject. State which per item.
