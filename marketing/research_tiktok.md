# TikTok Research Findings

_Last updated: 2026-06-25_

## Niche landscape
UK money-tips/tax-explainer content is an active, populated niche — "tax explained," "self-employed UK," and "money tips" style content performs well, especially around tax-year deadlines (January Self Assessment deadline, April new-tax-year). MTD itself is a fresh, less-saturated sub-angle within that niche because the rollout is new and most people genuinely don't know if/when it affects them.

## Formats currently performing (per 2026 trend research)
- **Faceless POV with text-on-screen** — voiceover or AI voiceover over B-roll/screen recordings, captions burned in. Lower production barrier, fits a calculator/tool demo well (screen-record the tool in use).
- **Longer-form (1-3 min)** is now outperforming ultra-short clips on watch time and FYP distribution — counter to the old "shorter is always better" assumption. Gives room to actually explain the threshold logic, not just a hook-and-link.
- **Hook discipline** — first 3 seconds decide whether anyone stays. Needs to lead with the anxiety/question ("Do you know when MTD affects you?") not a slow setup.

## How this maps to our content pillars
1. **"Am I affected and when?"** → screen-record someone using the calculator live, narrate the result. Strong hook: "If you're self-employed and don't know this date, you need to."
2. **"What do I actually do about it?"** → software comparison / "what MTD-ready software actually looks like" walkthrough.
3. **"What happens if I get it wrong?"** → factual, reassuring explainer on the penalty points system and the 2026/27 soft landing — calm, not scary.

## Posting mechanics (hard constraint)
- The only ToS-compliant automated posting path is TikTok's official **Content Posting API** (OAuth2-based), capped around 15-25 posts/day per account, shared across any API clients used.
- We will not build or use any unofficial/scripted posting workaround — that's a bannable automation violation regardless of content quality.
- Until the official API is set up and you've approved its use, every video is a **package** (script, hook, shot list, on-screen text, caption, hashtag suggestions) handed to you to actually shoot/edit and post yourself, or to queue once the API is connected.
